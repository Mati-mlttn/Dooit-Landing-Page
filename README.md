# Doo It! Landing Page

Official website for **Doo It!**, a privacy-focused Android workout app designed to make training simple, visual, and distraction-free.

[Visit dooitfitness.com](https://dooitfitness.com)

## About

This landing page introduces the app, presents its main features, and provides access to the closed beta program.

### Highlights

- Responsive design for desktop, tablet, and mobile
- English and Spanish support
- Smooth scrolling and optimized visual assets
- Accessible, privacy-conscious beta registration
- Automatic deployments through Vercel

## Built With

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vercel](https://vercel.com/)

## Local Development

Requirements:

- Node.js 22 or newer
- pnpm

Install the dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Private environment configuration is not included in the repository. The public landing page can still be developed locally without enabling beta services.

## Available Commands

```bash
pnpm dev      # Start the development server
pnpm build    # Create a production build
pnpm start    # Run the production build
pnpm lint     # Check the codebase
```
